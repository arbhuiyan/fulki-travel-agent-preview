# Fulki Connect — agent portal preview

Static build of the agent portal (`arbhuiyan/fulki-travel`, branch `main`, `frontend/`),
served by GitHub Pages at https://connect.fulkitravels.com/ (custom domain, see `CNAME`).
Everything is mocked in the browser; no backend.

Don't edit these files by hand: rebuild with `npm run build` in `frontend/` and copy `dist/` here,
keeping `CNAME`, `.nojekyll` and this README.
